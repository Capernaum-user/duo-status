# duo-status

claude-duo 파이프라인(기획 ↔ 워커 세션 핸드오프)의 **작업 현황 공개 보드**입니다.
어떤 작업(job)이 어느 라운드에서 진행 중인지, 교차검증 상태는 무엇인지를 읽기 전용 스냅샷으로 보여줍니다.

🔗 **라이브:** https://capernaum-user.github.io/duo-status/

## 이 보드가 보여주는 것

- 진행 중/완료된 작업(job)의 상태 카운트
- 교차검증(externalVerifies) 결과 요약
- 최근 호출(invocations) 이력

## 커밋에 대한 정직한 안내

이 저장소의 커밋은 사람이 직접 만들지 않습니다. **로컬 자동 발행 봇이 정기적으로 스냅샷을 생성해 push합니다.**
커밋 빈도를 활동량의 증거로 해석하지 마세요 — 이 저장소는 대시보드 산출물이지, 코드 작업 이력이 아닙니다.

## 관련

- 파이프라인 코드 자체(claude-handoff)는 비공개 저장소에서 관리됩니다.
